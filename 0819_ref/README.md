# 레퍼런스 — Plastic Type

코드 주석은 이 이미지들을 **번호가 아니라 이름으로** 부른다. 번호는 폴더를 한 번
정리하면 뜻을 잃고, tool 01의 레퍼런스 번호와도 겹쳤다.

| 파일 | 주석에서 부르는 이름 | 무엇을 가르쳤나 |
|---|---|---|
| `01-kiosque-bridged-column.jpg` | **the bridged column** | Le Kiosque 포스터. 세로 1열 · 브리지로 이은 격자 · 글자보다 얇은 벽 · 사출탭과 명판 없음 · 2색. **사용자가 지정한 최우선 레퍼런스**이고 현재 기본값이 여기에 맞춰져 있다. `Tie frames` ON이 이것이다. |
| `02-syllable-runners.jpg` | **the syllable runners** | 음절마다 색이 다른 낱개 런너 넷. 각 프레임이 자기 음절에 딱 맞게 잘려 있어서 넷으로 읽힌다. `Tie frames` OFF · `Per runner` 색이 이것이다. `이`의 ㅇ과 ㅣ가 제자리에서 각각 물려 있다. |
| `02b-syllable-runners-close.jpg` | 위와 같은 작업 | 클로즈업. 사출탭과 게이트 목이 보인다. |
| `03-bandai-sprue.jpg` | **the Bandai sprue** | 실제 프라모델 스프루. 명판(런너 글자 + 부품 번호), 사등각 돌출, 가지에서 가지가 갈라지는 직각 골격. 3D 돌출은 아직 안 한 항목이다. |
| `04-spare-parts-frame.jpg` | **the spare-parts frame** | SPARE PARTS. 내부 격자 바가 프레임을 칸으로 나눠 가운데 부품까지 닿는다(`Cell bars`). 긴 부품을 양 끝에서 잡는 것도 여기서 왔다. 명판과 사출탭도 있다. |

`03`과 `04`가 3D / 평면으로 갈리지만 명판·사출탭은 둘 다 갖고 있다.
